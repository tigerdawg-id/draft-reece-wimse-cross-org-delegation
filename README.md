# draft-reece-wimse-cross-org-delegation

Requirements for Cross-Organization Delegation of Authority to AI Agents.
An individual Internet-Draft in the scope of the IETF [WIMSE working
group](https://datatracker.ietf.org/wg/wimse/about/).

**Current revision:**
[datatracker](https://datatracker.ietf.org/doc/draft-reece-wimse-cross-org-delegation/)
· [latest text](https://www.ietf.org/archive/id/draft-reece-wimse-cross-org-delegation-02.txt)

Author: Morgan Reece (list handle `morganLR`), TowerGuardian Consulting.
